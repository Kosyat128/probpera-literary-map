# Редакционные заставки разделов

Дата подготовки: 2026-08-08.

Три изображения созданы специально для сайта «Проба Пера» с помощью
генерации изображений OpenAI. В исходные промпты были включены требования:
без текста, букв, логотипов, водяных знаков и пера; единая баклажаново-янтарная
палитра; центральная безопасная зона для адаптивного кадрирования.

- `literary-calendar.webp` - календарь, часовой механизм, книга и сезонные
  листья как образ литературной памяти и хода времени.
- `readers-forum.webp` - круглый стол читательского клуба, книги, кресла и
  тёплый свет как образ разговора о литературе.
- `about-editorial.webp` - редакционный стол, корректура, лупа и печатный
  станок как образ проверки фактов и ручной редакционной работы.

Файлы сохранены в WebP без встроенного текста. При использовании в интерфейсе
на них накладываются только доступные HTML-заголовки карточек.
