# «Проба Пера» — литературная карта мира

Интерактивный литературный журнал и энциклопедия: музейный 3D-глобус,
страны, писатели, произведения, книжный архив, статьи, календарь,
читательские рейтинги, комментарии и защищённая редакционная система.

## Архитектурный принцип

`src/data/countries` — единственный главный источник энциклопедических данных.
Цепочка данных неизменна:

`глобус → страна → писатели → произведения → статьи и обсуждения`.

Папка `writers` не является второй базой и не должна дублировать сведения
о странах.

## Основные команды

```text
npm install
npm run dev
npm run lint
npm test
npm run build:all
npm run release:check
npm run build:domain
```

Публичная часть собирается в `dist`. Редакционная панель находится в
`apps/admin`, использует адрес `/admin` и требует серверного Next.js-хостинга.
