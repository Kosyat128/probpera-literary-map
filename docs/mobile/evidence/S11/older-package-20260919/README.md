# Previous optional package version

The offered version and the saved version are separate. A trusted previous pin
can authorize removal only when it is the actual current selected generation.
The confirmation binds its version and exact selection receipt. A previous
generation behind an unknown newer current selection remains protected.

`unit-a1` passed 138 cases. The original removal Chrome case passed in
`browser-a1`. Its new previous-version case failed during fixture CacheStorage
seeding, before app assertions. The temporary profile prefix was shortened to
avoid deep Windows profile paths; only that failed case was rerun. `browser-a2`
passed removal of saved v2 with offered v3, offline restart and explicit v3
installation. Both runs and the setup error are preserved. No app source changed
between those browser attempts. RU/EN confirmation screenshots were inspected
at their original resolution.

The final source binding, shared TypeScript result and artifact links are recorded
by the combined reader checkpoint. Native device acceptance remains open.
