# Receipt-bound inspection in package management

This slice connects the staged semantic inspector to the platform-lifetime
downloads controller through explicit trusted `adult-candidate-v1` descriptors.
Generic packages keep their existing behavior. Full immutable staged views stay
outside React snapshots and never replace the bundled literary dataset.

Focused tests cover observation lifetime, exact receipts, mutation races, shared
package rows, and background/disposal. One browser case uses real preserved S08
bytes, the web adapter, browser persistence and the bilingual downloads panel.
This is controlled local QA, not production content activation or device proof.

The production download catalog and trust registry remain empty. Existing exact
PWA and Android artifacts remain preserved until the next runtime build batch.
