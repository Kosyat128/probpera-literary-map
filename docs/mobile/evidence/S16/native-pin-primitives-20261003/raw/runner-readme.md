This helper is adapted from the retained `next-native-pin-session-runner-a1/run-jvm.mjs`. Authoring and source review do not execute it. Only root runs the frozen successor once, before integrating the new native sources.

It requires exact clean report `d82b5219604689102c31f8e6206929975bb0153c`, app source `17843151ab0624b2b17102440d0eeb464381bdcb`, the unchanged1780-file captured closure, original project Java bytes, frozen Android primitive candidate and the existing frozen39-case session driver. The one compiler command builds the candidate Java source, new24-case primitive driver and unmodified39-case session driver together. The existing codec69 cases are not repeated. The core39 regression is needed because native commit claim now denies overlapping actual primitive workers.

One independent Node `crypto.pbkdf2Sync` call computes a fixed public vector: password bytes49..56, salt bytes00..1f,600000 iterations,32-byte output,SHA256. `public-pbkdf2-oracle.json` records actual execution, expectedHashHex and Node executable hash; the same receipt can supply a future separately executed Swift comparison. It contains no user's PIN. Each Java driver has its own raw stdout/stderr, command receipt, counts and scope. A new-driver failure does not suppress the independent core39 run after successful compilation.

The primitive result is host-JVM platform crypto with explicit synthetic session/authority/input fixtures. It proves no installed Android provider/storage/UI/lifecycle, genuine native authority, account/system recovery, Parent Gate admission or App registration. Swift compilation and all authored Swift tests remain unperformed.

Subprocesses use exact pinned JDK/Android-jar paths, `shell:false`, an environment allowlist and this new UUID attempt's temp/home directories. Git reads use the physical checkout's per-process safe.directory, no replace objects, no lazy fetch, no prompts and no optional locks. No project, original candidate, previous evidence, Git refs/config or global environment is written. All failed attempts are preserved.

The frozen runner accepts only the optional exact `--report-head d82b5219604689102c31f8e6206929975bb0153c` argument. It creates a fresh `attempt-<UUID>` under its own B directory; no author execution has occurred.
