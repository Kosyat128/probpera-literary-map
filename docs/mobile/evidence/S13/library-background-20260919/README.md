# S13 original included library background

The two-level reading hall binds `background.base.library` to the included
`probpera-library-3d` scene. It is distinct from the optional grand library.
The unchanged canonical starfield remains the default and fallback. Only the
background branch of the existing scene changes; camera, globe, stand, common
lights, geography, country and writer retain their existing owners.

The hall has foreground architecture, midground shelves/gallery and an opaque
outer room. Original unlettered books and repeated architecture use instancing.
Tier detail reduces geometry, instances and owned material-map resolution.
Following the user's explicit quality clarification, the initial block geometry
is being replaced with detailed casework, architectural profiles, bindings and
page blocks. Locally generated albedo, roughness and normal tiles distinguish
wood, brass, leather, paper and stone. Material-local window reflections do not
replace the shared scene environment. At most two bounded room lights have no
reach into the canonical globe. Vertex/contact cues are not a certified lightmap
or art approval. No downloaded textures or external protected designs are used.
The shared camera still has its full movement envelope: the audit checks each
transformed triangle, including instance transforms, against a radius-5.6 sphere.

Exact local compatibility permits known canonical editions, stands and tiers
in the current adult app path. Unknown or child requests fail closed. Source
metadata does not grant rights, editorial review, child access or an entitlement.

Stand and background controls share a nonmodal RU/EN appearance panel. Switching
categories cancels the previous draft. The shared controller retains the stand
API and isolates queues by preference key: a slow background write cannot block
a stand save, while old writes to the same key remain ordered across remounts.
Apply follows a real rendered frame and commits the session choice; unconfirmed
saving offers retry. This is not full-composition atomic persist-or-rollback.

Background/foreground and actual WebGL recovery gate restoration and preview
without pretending that a suspended read was an explicit user choice. Ambient
lamp variation runs only with active, non-reduced-motion rotation; it neither
owns nor forces the render loop.

`run-checks.mjs` records mode-specific source hashes and separate attempt paths.
Focused units include the unchanged stand lifecycle cases plus new background,
key isolation, face clearance, tier and owned-map/resource cases. Two actual Chrome cases
include the visual captures, depth/parallax, canonical ownership, persistence,
locale, ambient pause and real context recovery. Their native OS ports are
controlled; the app and renderer are real.

`capture-craft.mjs` produces additional close-up images of the actual geometry
factories under the canonical lighting palette. These isolated art-inspection
views complement actual-App captures; they do not prove app camera/UI behavior.
CPU submission timings in that tool are not GPU timings or installed-device FPS.
The initial unit/static/browser a1 reports remain historical functional-prototype
attempts. New geometry/material changes require a new source-bound attempt.

Final accepted reports, source commit and refreshed artifacts belong in
`result.json`. All attempts are retained. Full scene catalog/Background Studio,
whole-composition transaction, reviewed child scenes, formal rights/art review,
device FPS/memory/soak and release acceptance remain open. S13 is in progress;
S03 remains the first open stage. No production actions are part of this slice.
