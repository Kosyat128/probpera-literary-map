Confirmed defect:

Patch:
- ProductNoticeHost owns one detached-created DOM container and one stable createPortal target.
- Slots are presentation-only: fallback (access closed), root (inside globe main), panel (active Collection). Active panel has highest priority.
- Only that container is reparented; React continues rendering the same notice subtree, preserving PwaConnectivity dismissal state and worker subscription. No auth/controller changes.
- Panel notice slot is inside the dialog, between header and scrollable content. Its own bounded scroll row reserves reader space. Existing trap and focus return need no custom outside exceptions.
- Root slot falls under existing launch/globe inert ownership. Without a provider, native/public slots return null.
- Existing help, locale controls, App/globe renderer/camera and license behavior remain owned by their current components.
