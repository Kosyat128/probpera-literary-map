# ПРАВИЛА ИСПОЛЬЗОВАНИЯ ВИЗУАЛЬНОГО ЭСКИЗА — V12

Файл `47_OWNER_VISUAL_REFERENCE.png` является композиционным референсом,
а не набором production-assets и не точной готовой UI-спецификацией.

Использовать из эскиза:

- общую последовательность экранов;
- центральную роль живого глобуса;
- orange branded launch;
- live customization preview;
- Планетку как guide;
- writer list/profile;
- store/catalog structure;
- child/adult visual distinction.

Не переносить из эскиза автоматически:

- нарисованные/вымышленные portraits;
- fake flags;
- fake prices/currency;
- typo/mixed-language text;
- unavailable Disney/other characters;
- generated covers;
- generic black game UI;
- multiple competing orange CTAs;
- screenshots как runtime assets.

Codex обязан создать `SKETCH_TO_SCREEN_SPEC.md` и для каждого элемента
отметить:

- retain;
- refine;
- replace with canonical site asset;
- remove as misleading;
- block pending rights;
- implement as real interaction.

Финальный UI должен быть качественнее эскиза и строго соответствовать
канону сайта: warm violet surfaces, canonical orange actions, real globe,
real portraits/flags, verified text and accessible responsive controls.
