# DISNEY LICENSED COLLECTION V12 — PRODUCT CATALOG AND RIGHTS CONTRACT

## 1. Purpose

This file adds Disney character worlds to the product plan while
preventing unauthorized use.

It is a candidate catalog only. It is not permission, a license, an
art-source list or a request to generate Disney-like characters.

All records start:

```text
legalStatus = LICENSE_REQUIRED
rightsEvidenceStatus = MISSING
publishStatus = BLOCKED
storeStatus = HIDDEN
assetStatus = NO_PRODUCTION_ASSET
marketingStatus = PROHIBITED
skuStatus = DISABLED
```

## 2. Non-negotiable rule

The paid Base Edition must be complete without Disney.

Disney packs:

- optional;
- non-consumable;
- separate from core education;
- hidden until licensed;
- available only on approved platforms/territories/languages;
- never promoted to children before ownership;
- purchased only by adult/Parent Gate;
- not required for child mode.

## 4. Out of initial V12 scope

Marvel and Star Wars may be Disney-owned franchises but are not
automatically part of the child literary product.

They require:

- separate owner request;
- separate educational rationale;
- separate age/sensitivity review;
- separate license;
- separate store positioning.

Do not add them silently.

## 6. Required approval pipeline

```text
candidate
→ owner commercial approval
→ licensing inquiry
→ signed agreement
→ contract metadata
→ approved asset delivery
→ checksum/provenance
→ child editorial review
→ age policy
→ platform/territory configuration
→ sandbox SKU
→ implementation
→ licensor approval
→ store review
→ controlled release
```

No stage can be skipped.

## 7. Asset rules

Allowed only after license:

- licensor-supplied art;
- licensor-approved commissioned art;
- licensor-approved 3D model;
- approved animation;
- approved text;
- approved audio.

Forbidden:

- screenshots from films;
- scanned merchandise;
- fan art;
- marketplace model without sublicensable rights;
- AI imitation;
- traced silhouette;
- copied palette/costume/model;
- voice cloning;
- unapproved music;
- extracted game assets;
- use in app icon/title without permission.

## 8. Child commerce

Disney pack is not visible in child store.

Child sees it only when:

- adult owns it;
- asset installed;
- childSafe = true;
- exact age allowed;
- territory and license valid.

The purchase flow is adult-only behind Parent Gate.

Планетка never says:
- “Купи”;
- “Попроси купить”;
- “Осталось мало времени”;
- price/discount messages.

## 9. Educational integrity

Every active Disney world has a declared content type:

- `LITERARY_ADAPTATION`;
- `SCREEN_ORIGINAL`;
- `MIXED_SOURCE`.

For `LITERARY_ADAPTATION`, show:

- original work;
- author;
- country;
- date/context;
- separate Disney adaptation notice.

For `SCREEN_ORIGINAL`, do not invent a book source.

## 10. Store metadata

Without explicit marketing rights, do not use:

- Disney name;
- Disney logo;
- character name;
- character screenshot;
- pack art;
- franchise keywords;
- licensed claim.

The generic application listing must remain valid without Disney.

## 11. Expiry and delisting

Before first sale define:

```text
postTermPolicy:
- retain existing purchasers;
- stop new sales, retain installed;
- revoke with refund;
- contract-specific.
```

Create:

- expiry alerts;
- territory kill switch;
- delisting action;
- safe included fallback;
- support copy;
- refund handling;
- content migration;
- audit log.

- signed agreement;

- territory;
- language;
- IAP permission;
- marketing permission;
- child review;
- age band;
- royalty model;
- post-term policy;
- sandbox evidence;
- licensor approval;

## 13. No-blocking guarantee

Disney licensing cannot block completion of:

- paid Base Edition;
- child mode;
- Планетка;
- original StoryWorlds;
- App Store/Google Play/RuStore/Web release candidates.

If Disney rights are absent, the entire Disney catalog remains hidden and
the app releases without it.
