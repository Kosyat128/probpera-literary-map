# STORE METADATA AND SCREENSHOT TRUTH — V12

## 1. Exact-build rule

Every screenshot and preview is traceable to:

- store;
- platform;
- version/build;
- commit SHA;
- content version;
- device/simulator;
- locale;
- date;
- source image checksum.

Use the exact release candidate. Re-capture after any visible code/content
change.

## 2. Concept reference prohibition

`47_OWNER_VISUAL_REFERENCE.png` and other concept collages are design
references only. Add a visible internal notice and exclude them from all
store export scripts.

## 3. Screenshot plan

Minimum truthful set:

1. Main Home with canonical globe.
2. Live 3D globe/country selection.
3. Real writer profile with approved portrait and flag.
4. Search/collection.
5. Child Home with Планетка.
6. Child literary journey.
7. Included customization Starter Set.
8. Optional adult store with honest localized price.
9. Parent Center/age controls.
10. Offline/download mode.

Only submit the number/formats currently required by each store.

## 4. Real content

Screenshots must use:

- canonical globe;
- real country;
- canonical SVG flag;
- verified writer;
- approved real portrait or faceless placeholder;
- verified biography/work;
- actual included skin/stand/background;
- actual UI translations.

No fictional placeholder writer, generated face, fake flag, fake quote or
mock purchase price.

## 5. Licensed content

Do not show Disney/Pixar or any protected candidate unless:

- the exact asset is licensed;
- store marketing rights are explicit;
- territory/platform/language permit it;
- licensor approved the capture;
- the exact build contains the approved pack.

“Coming soon” is not a rights exception.

## 6. Metadata claims

Allowed factual claims must be generated from actual build/report:

- number of verified writers;
- number of countries;
- included Starter Set;
- offline availability;
- no ads/subscription;
- child mode;
- optional purchases.

Avoid:

- best/number one;
- official without evidence;
- largest in the world;
- guaranteed educational outcome;
- all books/authors if not literally complete;
- Disney availability before license;
- functionality only planned.

## 7. App naming

Default:

- Name: `Литературная планета`
- Subtitle/tagline: `Проба пера`

Store character limits are checked automatically at RC.
Installed app label is compared with listing.

## 8. Optional purchase disclosure

Copy should state:

- application is a one-time paid purchase;
- core library, child mode and Starter Set included;
- additional cosmetic themes are optional;
- no subscription or ads.

If an image shows optional content, label it clearly without making the
image deceptive.

## 9. Post-processing

Permitted:

- crop;
- device frame;
- background composition;
- readable captions;
- privacy-safe redaction;
- localization.

Forbidden:

- inserting unavailable screens;
- changing product price;
- adding unlicensed characters;
- replacing real portrait;
- altering UI to imply features;
- hiding a blocking error;
- editing a mock state into success.

Maintain a post-processing log.

## 10. Automated gates

- dimensions/count;
- title/description length;
- banned claims;
- banned store badges;
- Disney/protected keyword scan;
- concept asset scan;
- screenshot hash/build mapping;
- OCR/text-language check where practical;
- visual regression against RC;
- optional-purchase disclosure;
- no debug/status bar secrets.
