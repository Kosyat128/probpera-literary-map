# VISUAL AND UX CANON

## Brand

Extract current canonical values from repository:

- orange;
- violet/dark violet;
- paper/ivory;
- text;
- focus;
- typography;
- radii;
- shadows;
- spacing.

Do not invent replacement brand values when repository tokens exist.

## Launch

- native orange splash;
- no white/black flash;
- branded bridge on same orange;
- official quill/logo at top-left after safe area;
- calm transition;
- real globe runtime after bootstrap;
- no giant duplicate logo;
- reduced motion.

## Adult visual character

- literary;
- museum;
- journal;
- warm library depth;
- canonical stars/sky;
- premium but restrained;
- not generic black game UI;
- paper/ivory reading surfaces;
- one dominant primary CTA.

## Navigation

Adult:

- Главная;
- Поиск;
- Планета — central action;
- Коллекция;
- Профиль/Настройки.

Store через «Оформление», current theme card или secondary entry, а не
центральное образовательное меню.

Child:

- Планетка;
- Планета;
- Авторы/Герои;
- Моё.

Parent Center via small lock + gate.

## Buttons

- Primary: canonical orange, one dominant per screen.
- Secondary: violet/tonal.
- Tertiary/Ghost: supplementary.
- Icon: minimum 44x44 and accessible label.
- Destructive: separate danger treatment.

No emoji as functional icon.
No orange outline on every card.
No fake currency.
No competing primary buttons.

Each needs phone 320/390/430, tablet, landscape, large text and
reduced-motion states.

## Real assets

Writer screens use real approved portraits and real flags.
No portrait from a generated collage becomes production asset.
Visual reference guides composition only.

## Globe

- same canonical surface/geography as site;
- one Canvas;
- no remount on theme/background/stand;
- overlays avoid useful map regions;
- mascot limbs fit in frame;
- Explore prioritizes geography;
- same semantic camera/picking.

## Evidence

For each visual stage save reference, implementation screenshot,
side-by-side/diff, intentional differences, accessibility report,
safe-area report, tap-target report and provenance confirmation.
