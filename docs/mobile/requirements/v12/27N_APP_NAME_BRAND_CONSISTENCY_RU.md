# APP NAME AND BRAND CONSISTENCY — V12

## 1. Default

- Public app name: `Литературная планета`
- Subtitle/brand: `Проба пера`
- Legal seller: verified developer account entity
- Domain: probpera.ru
- Bundle/package: owner-approved stable identifiers

## 2. Why short name

The long form «Литературная планета — Проба пера» may exceed store title
limits. Use name and subtitle fields rather than truncating unpredictably.

## 3. Consistency matrix

Compare:

- App Store name;
- Google Play title;
- RuStore name;
- PWA short_name/name;
- installed label;
- splash;
- About;
- privacy policy;
- support;
- review notes;
- app icon;
- package/bundle identity.

Differences require explicit platform rationale, not accidental drift.

## 4. Brand evidence

Prepare:

- proof of domain control;
- logo source/provenance;
- owner approval;
- legal seller relationship to brand;
- trademark records if available;
- contact email/domain;
- brand usage guide.

## 5. Forbidden

Without evidence:

- “официальное”;
- Disney/Pixar in title;
- competing app names;
- SEO keyword stuffing;
- emoji/decorative symbols that mislead;
- price/discount in title;
- unsupported age claim.

## 6. Asset consistency

Icon:

- official project mark;
- correct adaptive/iOS/PWA variants;
- no unlicensed character;
- no store badge;
- no tiny unreadable text;
- correct safe zone;
- deterministic source.

Splash:

- canonical orange;
- official logo;
- no mismatch with icon/name.

## 7. Automated tests

- current character limits;
- installed/listing match;
- package/bundle match;
- privacy/support app name match;
- no protected terms;
- localized names;
- icon hash inventory;
- no obsolete brand asset.
