# FINAL BILINGUAL NO-RETURN CONTRACT / НЕ ВОЗВРАЩАТЬСЯ К ТЗ V12

After FINAL HANDOFF, the owner must not need a new specification to complete
English support.

Codex must have already delivered:

- full ru/en UI and Base Edition content;
- verified names/titles and cross-script search;
- translation workbench, glossary, memory, stale handling and rollback;
- English Child Mode, Planetka, audio/transcript policy and offline package;
- iOS/Android per-app language and state-preserving in-app switch;
- App Store, Google Play, RuStore and Web/PWA localized packages;
- Russian/English exact-RC screenshots and reviewer instructions;
- synchronized legal/privacy/support documents;
- Web SEO/canonical/hreflang/sitemaps;
- translation-provider governance;
- editorial correction workflow;
- machine-readable evidence and quality scorecard;
- bilingual owner approval and post-build guides;
- zero owner translation/programming task.

The following cannot be deferred as “later localization” for the Base
Edition: critical errors, purchase/Restore, child safety, privacy/deletion,
legal/support, offline failure states, accessibility labels, native dialogs,
writer/work core content, store claims or reviewer routes.

Future third languages use the same architecture, but V12 release completion
requires only fully approved Russian and English. No third locale may weaken
or delay the two-locale release.
