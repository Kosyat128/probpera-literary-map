## Получить рабочую копию

Установить Git, Node.js 24.x и Python 3.11 или новее. Последние выполненные
проверки использовали Node.js 24.18.1 и Python 3.14. Зависимости устанавливать
из сохранённого `package-lock.json`.

```powershell
git clone --branch codex/admin-r3-data-errors https://github.com/Kosyat128/probpera-literary-map.git
cd probpera-literary-map
git log -1 --oneline
npm ci
python scripts/restore-admin-r3-continuation.py --verify
python scripts/restore-admin-r3-continuation.py
```

Последняя команда проверяет архив и восстанавливает его **рядом с репозиторием**
в новую папку `work`. Существующая папка не перезаписывается. При совпадении
имени выбрать новую папку через `--destination`; исторические сценарии затем
адаптировать к выбранному расположению. Сам архив находится в
`docs/admin-r3-continuation/2026-11-11/continuation-work.zip`; его перечень
и SHA-256 находятся в соседних файлах.

Если используется файл переноса Git, сначала клонировать ветку с GitHub,
затем получить сохранённый коммит из bundle:

```powershell
git fetch "ПОЛНЫЙ_ПУТЬ_К_ФАЙЛУ.bundle" refs/heads/codex/admin-r3-data-errors
git merge --ff-only FETCH_HEAD
```

Bundle содержит изменения поверх `acb910d8` и требует наличия этого базового
коммита. Он служит дополнительной копией; при обновлённой ветке GitHub достаточно
обычного клонирования. Не выполнять reset, force push или замену чужих правок.
