# Site Studio: инструкция оператора

Site Studio открывается по маршруту `/site-studio` и состоит из четырёх рабочих разделов: **компоненты**, **токены**, **шрифты** и **релизы**.

## Безопасный рабочий процесс

1. Выберите зарегистрированный компонент или группу токенов.
2. Изменяйте только параметры, предложенные типизированной формой.
3. Проверьте предпросмотр и адаптивные состояния.
4. Сформируйте набор изменений.
5. Опубликуйте его как атомарный релиз либо отмените через историю релизов.

Студия использует закрытый контракт значений и не является редактором произвольного CSS, HTML или JavaScript. Это ограничение сохраняет предсказуемую адаптивность и не позволяет административной настройке менять поведение приложения вне зарегистрированной поверхности.

## Компоненты и защищённые области

Реестр компонентов задаёт доступные оператору параметры. Компоненты глобуса и книжной полки помечены как `ownerLocked`: через Site Studio нельзя менять их геометрию, интерактивную механику или снять это ограничение. Разрешены только безопасные параметры, явно присутствующие в контракте.

## Токены и адаптивность

Токены управляют предусмотренными цветами, типографикой, интервалами и семантическими ролями. Адаптивные значения задаются через разрешённые роли/режимы; произвольные брейкпоинты и CSS-вставки не принимаются.

## Шрифты

Менеджер шрифтов работает с предусмотренными локальными форматами WOFF/WOFF2, данными происхождения и лицензии и назначением на семантические роли. Подключение удалённого CSS как шрифта не является поддерживаемым сценарием.

## Релизы и откат

Публикация Site Studio оформляется как единый релиз: частично применённое состояние не считается успешным. Для возврата используйте раздел релизов и штатный откат, а не ручное редактирование записей. При конфликте или сбое следуйте [runbook восстановления](./ADMIN_RECOVERY_RUNBOOK_RU.md).

Подтверждение реализации: `apps/admin/app/(dashboard)/site-studio`, `apps/admin/lib/site-studio-contract.ts` и канонический контракт `src/data/cms/siteStudioContract.ts`.
