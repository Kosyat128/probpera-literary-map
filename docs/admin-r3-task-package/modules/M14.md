### M14. Аналитика, определения и связь с материалами — P2

**Основание.** Есть внутренний агрегированный отчёт, CSV и ссылка на Метрику с фиксированным month. Он не должен выдаваться за полный маркетинговый отчёт или точный подсчёт физических людей. [E17]

**Реализация.** Явно показывать период, часовой пояс, источник, область покрытия и определения просмотров/анонимных идентификаторов/зарегистрированных профилей. Не приравнивать их друг к другу. Экспорт CSV, графики, суммы и фильтры используют один диапазон. Для ссылки на внешний отчёт применять только реально поддерживаемые параметры; если точный диапазон передать нельзя, прямо подписать иной диапазон, а не подделывать URL.

Добавить измерения article/book/section/locale там, где события уже позволяют достоверную связь, и понятные названия с переходом в редактор. Неразрешённые идентификаторы показывать как неизвестные, не связывать догадкой. Раздельно обрабатывать отсутствие наблюдений и ошибку отчёта.

Инвентаризировать события полезных действий: открыть книгу из статьи, сохранить в подборку, открыть источник, пройти существующий сценарий. Добавлять только минимально необходимые события существующих функций, не изобретать продуктовые сценарии ради графика. Доля рассчитывается по явно подписанному знаменателю, фильтры RU/EN согласованы. Воронку показывать лишь при достаточных событиях и явном определении шага; не считать удержание из одних pageviews.

Не сохранять тексты статей, запросы админского поиска, полные URL с чувствительными параметрами, email и токены. Не менять существующую политику согласия/retention, не добавлять сторонний трекер. Исключение внутренних/test-событий — по доказуемому признаку; не заявлять полную фильтрацию ботов, если она не реализована. CSV защищён правами и экранированием формул; приватные данные в нём минимальны.

**Приёмка.** Числа таблицы/графика/CSV на одних fixtures совпадают, периоды не расходятся скрыто, недостаточные данные не превращаются в выдуманные конверсии.

**Уточнение R2.** Выбранный диапазон, локаль, часовой пояс и фильтры должны совпадать в KPI, деталях и выгрузке; переход к внешней Метрике явно показывает другой период, если точная синхронизация не поддерживается. CSV обрабатывает формулы, кавычки, переносы и разные spreadsheet-клиенты без утечки идентификаторов. Новые события сначала валидируются схемой и тестами; не включать тело draft, пользовательские поисковые запросы, email, токены или URL с секретами.
