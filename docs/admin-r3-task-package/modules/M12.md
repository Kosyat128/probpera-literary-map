### M12. Навигация, поиск и доступность админки — P2

**Основание.** Общий module registry уже существует; sidebar использует его без фильтрации по роли. Ctrl+K ищет разделы, а не статьи и книги; у модального компонента нужно завершить управление фокусом. [E15]

**Реализация.** Расширить существующий registry группой, permission/capability и кратким описанием. Предлагаемые группы: «Материалы», «Книги и авторы», «Оформление», «Публикация и контроль», «Управление». Сохранить старые routes и прямые ссылки. Избранное/недавние — опциональный компактный слой без сохранения приватных названий в общедоступном browser storage. Не создавать второй источник меню.

Видимые действия соответствуют серверным правам. View-only явно подписан. Недоступный по роли пункт не выдаёт закрытые данные через command search. Реальную проблему схемы не скрывать как якобы отсутствие прав.

Быстрый переход оставить навигацией; добавить отдельные результаты глобального поиска по разрешённым сущностям через общий серверный search-адаптер с limit/debounce/cancel устаревших запросов. Результат показывает тип, язык, статус и контекст. Поиск досье/книг и обычный каталог используют согласованные идентификаторы и правила.

Фокус модального окна: начальный фокус, Tab/Shift+Tab внутри, Escape, возврат в вызвавший элемент, недоступность фона, корректное имя и выбранная опция. Не объявлять aria-modal без реального поведения. Использовать имеющийся подходящий примитив/стандартный dialog, а не добавлять библиотеку только ради одного окна. В комбинированном поиске согласовать роли combobox/listbox с реальным управлением. Переход учитывает unsaved guard редактора.

Проверить 320/375/768/1024/1440/1920 CSS px, 200% zoom и reflow при 400%, клавиатуру, экранный диктор выборочно, reduced motion. Боковая навигация на телефоне доступна, не заслоняет форму; широкие таблицы имеют управляемую область прокрутки/адаптивный список. Контраст и фокус используют текущие токены, не новый брендинг. У полей явные label; ошибки связаны aria-describedby, статусы имеют appropriate live region.

Все новые и изменённые ссылки/redirect/actions проверить при basePath='' и '/admin', без двойного префикса и без потери query. Не менять рабочий deployment basePath ради унификации исходников.

**Приёмка.** Пользователь может пройти полный основной сценарий клавиатурой и на узком экране; Ctrl+K не уводит из несохранённой формы без защиты; контентный поиск не раскрывает закрытые сущности.

**Уточнение R2.** Реестр разделов — не реестр безопасности. Сверить весь route tree и действие для каждой ссылки в боковом меню/quick-actions; неизвестный или игнорируемый query не должен создавать ложный рабочий переход. Поиск по закрытому содержимому разрешает только staff с текущей ролью, не отдаёт snippets/счётчики неподходящим аккаунтам. aria-modal без удержания/возврата фокуса не является завершённой доступностью. Проверки 400%/320 CSS px допускают осознанно горизонтально прокручиваемую таблицу внутри контейнера, но не весь документ и не недоступные кнопки.
