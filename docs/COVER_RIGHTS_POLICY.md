# Политика использования обложек «Проба Пера»

Эта политика нужна для редакционной и технической дисциплины. Она не заменяет
индивидуальную юридическую консультацию: срок охраны и допустимость использования
проверяются для конкретного изображения и юрисдикции.

## Основной принцип

Авторское право на текст книги и право на оформление конкретного издания — разные
объекты. Даже если произведение перешло в общественное достояние, современная
иллюстрация, фотография, шрифт или макет обложки могут охраняться отдельно.

Проект показывает обложку только при наличии `coverRights` с одним из статусов:

- `public-domain` — зафиксировано основание общественного достояния;
- `licensed` — сохранены название лицензии, ссылка и требуемая атрибуция;
- `permission` — редакция получила разрешение правообладателя;
- `editorial-original` — собственное художественное оформление «Пробы Пера»;
  после редакционного решения от 2 августа 2026 года оно может использоваться
  в книжном архиве только с явной подписью «Редакционная обложка» и не должно
  сопровождаться неподтверждёнными сведениями о конкретном издательстве или ISBN;
- `external-preview` — изображение не копируется в проект и показывается через
  документированный публичный сервис вместе со ссылкой на запись-источник.

Статус `unverified` автоматически блокирует изображение в книжном архиве.
Вместо него интерфейс рисует фирменную типографическую
карточку. Так иллюстрация или случайный кадр из статьи не выдаются за реальную
обложку конкретного издания.

## Open Library

Для внешних превью используется URL `covers.openlibrary.org`, как рекомендует
официальная документация Covers API. Рядом с книгой сохраняется ссылка на запись
Open Library. Изображения не скачиваются массово и не хранятся в репозитории.

В панели управления поиск выполняется только по корректному ISBN-10 или ISBN-13.
Система проверяет контрольную цифру и принимает метаданные лишь тогда, когда
ответ сервиса содержит тот же идентификатор. Поиск «похожей картинки» только по
названию или автору не используется.

Важно: Open Library прямо предупреждает, что у отдельных материалов могут
существовать права третьих лиц. Поэтому `external-preview` — не утверждение о
свободной лицензии и не разрешает локальное копирование файла.

- Документация Covers API: https://openlibrary.org/dev/docs/api/covers
- Поиск точного ISBN в Google Books API:
  https://developers.google.com/books/docs/v1/using
- Лицензирование данных Open Library:
  https://openlibrary.org/developers/licensing

## Wikimedia Commons

Файл с Wikimedia Commons можно публиковать только после проверки страницы самого
файла. В данных сохраняются автор, лицензия, ссылка на лицензию, страница файла и
дата проверки. Требования к указанию авторства переносятся в подпись изображения.

- Руководство по повторному использованию:
  https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia

## Редакционный процесс

1. Найти точное издание и страницу первоисточника.
2. Установить автора оформления или правообладателя.
3. Зафиксировать лицензию либо письменное разрешение.
4. Заполнить `coverRights`, включая `checkedAt`.
5. Запустить `npm run covers:audit`.
6. При сомнении оставить `unverified`: фирменная fallback-обложка безопаснее.
7. Для обращений правообладателей использовать
   `probperasite@yandex.ru`; спорное изображение снимается до повторной проверки.

## Чего не делать

- не брать изображения из поисковой выдачи;
- не считать отсутствие водяного знака разрешением;
- не переносить современную обложку в локальные assets без лицензии;
- не смешивать сведения об издании с правами на его оформление;
- не убирать подпись или источник, если лицензия требует атрибуции.
