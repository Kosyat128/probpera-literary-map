# Автопостинг «Пробы Пера»

После первой публикации статьи админка создаёт задание `social_publish.requested`.
Публичный workflow сначала обновляет сайт, затем отправляет материал в подключённые
каналы. Отдельный workflow каждые десять минут повторяет только незавершённые
задания, не пересобирая сайт. Результат каждого канала сохраняется в
`admin_audit_log` и отображается в редакторе статьи.

## Секреты GitHub Actions

В `Settings → Secrets and variables → Actions` репозитория должны быть созданы:

- `SUPABASE_SERVICE_ROLE_KEY` — серверный ключ очереди; никогда не помещать его
  в Vite или браузерный код;
- `VK_GROUP_ID` — числовой ID сообщества без минуса;
- `VK_GROUP_ACCESS_TOKEN` — токен сообщества для резервной публикации текста и
  ссылки. Для совместимости workflow также принимает старое имя
  `VK_ACCESS_TOKEN`;
- `VK_USER_ACCESS_TOKEN` — рекомендуемый пользовательский токен администратора
  сообщества с минимальными правами `wall` и `photos`: он нужен для надёжной
  публикации и загрузки обложки;
- `OK_GROUP_ID`, `OK_APPLICATION_KEY`, `OK_ACCESS_TOKEN`,
  `OK_SESSION_SECRET_KEY` — доступ приложения к группе в «Одноклассниках».

Все токены хранятся только как GitHub Actions Secrets. Их нельзя добавлять в
`VITE_*`, `NEXT_PUBLIC_*`, репозиторий или браузерный код.

Для Дзена используется `https://probpera.ru/rss.xml`: канал нужно один раз
подключить и проверить в кабинете Дзена. В текущем контуре прямой API Дзена не
используется — интеграция готовит полнотекстовый RSS для импорта.

Статус Дзена в панели означает «материал появился в RSS и готов к импорту».
Фактическое принятие публикации Дзеном проверяется в кабинете канала.

VK получает `owner_id=-VK_GROUP_ID` и `from_group=1`, поэтому публикация всегда
идёт от имени сообщества, а не на личную страницу администратора. Токен
сообщества используется только как текстовый резерв: актуальный VK API не
разрешает ему методы загрузки фотографии на стену даже при наличии разрешения
`photos`. Для обложки используется только `VK_USER_ACCESS_TOKEN`; при его
отсутствии материал всё равно отправляется как текст со ссылкой. Для OK
приложению и сессии требуется право `GROUP_CONTENT`; текущая интеграция
публикует текст и ссылку без прямой загрузки обложки.

Обязательными каналами сейчас являются VK и RSS Дзена. «Одноклассники» не
блокируют выпуск до завершения настройки их секретов.

## Мгновенная публикация сайта

Чтобы админка сразу запускала GitHub Pages, в серверном окружении админки задаются:

- `GITHUB_DEPLOY_TOKEN` — fine-grained token только для этого репозитория с
  разрешением Actions: write;
- `GITHUB_DEPLOY_REPOSITORY=Kosyat128/probpera-literary-map`;
- `GITHUB_DEPLOY_WORKFLOW=deploy-pages.yml`;
- `GITHUB_DEPLOY_REF=main`.

Токен хранится только на сервере админки. Если он временно недоступен, запрос не
теряется: он попадает в резервную очередь Supabase, которую workflow проверяет
каждые пять минут.

## Повторная отправка

На странице опубликованной статьи есть блок «Автопостинг публикации». Он показывает
отдельный статус «ВКонтакте», «Одноклассников» и Дзена. Кнопка повторной отправки
создаёт новое задание; использовать её следует только после исправления ошибки
доступа, поскольку в уже успешно подключённом канале может появиться дубликат.
Обычные временные ошибки повторяются автоматически отдельным последовательным
workflow; стабильный `guid` VK защищает одну и ту же заявку от повторного поста.
