# Автопостинг «Пробы Пера»

После первой публикации статьи админка создаёт задание `social_publish.requested`.
Публичный workflow сначала обновляет сайт, затем проверяет материал в RSS Дзена.
Отдельный workflow каждые десять минут повторяет только незавершённые
задания, не пересобирая сайт. Результат каждого канала сохраняется в
`admin_audit_log` и отображается в редакторе статьи.

## Секреты GitHub Actions

В `Settings → Secrets and variables → Actions` репозитория должны быть созданы:

- `SUPABASE_SERVICE_ROLE_KEY` — серверный ключ очереди; никогда не помещать его
  в Vite или браузерный код.

Все токены хранятся только как GitHub Actions Secrets. Их нельзя добавлять в
`VITE_*`, `NEXT_PUBLIC_*`, репозиторий или браузерный код.

Для Дзена используется `https://probpera.ru/rss.xml`: канал нужно один раз
подключить и проверить в кабинете Дзена. В текущем контуре прямой API Дзена не
используется — интеграция готовит полнотекстовый RSS для импорта.

Статус Дзена в панели означает «материал появился в RSS и готов к импорту».
Фактическое принятие публикации Дзеном проверяется в кабинете канала.

Обложкой Дзена автоматически становится первая пригодная HTTPS-иллюстрация в
порядке текста. Декоративные, слишком маленькие, скрытые и небезопасные
изображения пропускаются; отдельная обложка статьи используется только как
резерв. В полнотекстовом RSS ведущая иллюстрация располагается после вступления
и перед первым смысловым H2.

Автопубликация во ВКонтакте отключена и не блокирует выпуск. Код ручного VK-
публикатора сохранён только для аварийного операторского запуска: он требует
одновременно явного `SOCIAL_ENABLE_VK_AUTOPUBLISH=true`, добавления `vk` в
`SOCIAL_REQUIRED_PLATFORMS` и серверных VK-секретов. Штатные workflows этих
параметров и секретов не передают.

## Мгновенная публикация сайта

Чтобы админка сразу запускала GitHub Pages, в серверном окружении админки задаются:

- `GITHUB_DEPLOY_TOKEN` — fine-grained token только для этого репозитория с
  разрешением Actions: write;
- `GITHUB_DEPLOY_REPOSITORY=Kosyat128/probpera-literary-map`;
- `GITHUB_DEPLOY_WORKFLOW=deploy-pages.yml`;
- `GITHUB_DEPLOY_REF=main`.

Токен хранится только на сервере админки. Если он временно недоступен, запрос не
теряется: он попадает в резервную очередь Supabase, которую workflow проверяет
каждые пять минут.

## Повторная отправка

На странице опубликованной статьи блок «Автопостинг публикации» показывает
статус RSS Дзена и отдельно напоминает, что VK отключён. Кнопка повторной
проверки возобновляет существующее незавершённое задание без дубликата; если оно
уже завершено, создаётся новая проверка текущего RSS. Временные ошибки повторяет
отдельный последовательный workflow.
