# Редакционная система «Проба Пера»

## Что уже предусмотрено

- защищённый кабинет по адресу `/admin`;
- отдельные роли `owner`, `admin`, `editor`, не связанные с ролью обычного читателя;
- визуальный редактор статей с резервной копией в браузере;
- статусы: черновик, проверка, расписание, публикация, скрытие, архив;
- автоматическая история предыдущих версий и журнал действий;
- рубрики и теги;
- медиатека с обязательным alt-текстом, источником и лицензией;
- собственная модерация комментариев и собственная статистика;
- управление главной страницей, страницами, баннерами и меню;
- SEO-поля, канонический адрес и постоянные 301-редиректы.

## Первичное подключение

1. Создать резервную копию текущего проекта Supabase.
2. Применить базовую схему `supabase/schema.sql`, миграцию безопасности
   `supabase/migrations/20260727_community_safety.sql`, затем
   `supabase/migrations/20260728_cms_foundation.sql`,
   `supabase/migrations/20260728_reader_favorites.sql`,
   `supabase/migrations/20260730_literary_archive.sql`,
   `supabase/migrations/20260730_page_revision_history.sql` и
   `supabase/migrations/20260730_staff_management.sql`.
3. Скопировать `apps/admin/.env.example` в локальный `.env.local` панели и
   заполнить публичные параметры Supabase. Ключ `service_role` нельзя добавлять
   в переменные `NEXT_PUBLIC_*` и нельзя передавать браузеру.
4. Зарегистрировать владельца через Supabase Auth, затем один раз назначить его:

   ```sql
   insert into public.staff_memberships (user_id, role)
   select id, 'owner'
   from auth.users
   where email = 'ваша-почта';
   ```

5. Запустить `npm run admin:dev`. Локальный адрес: `http://localhost:3000/admin`.

## Перенос 157 существующих статей

Сначала выполняется только проверка:

```text
npm run content:import:cms
```

Для настоящего импорта нужны только серверные переменные
`SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `CMS_OWNER_USER_ID`.
После резервной копии запускать:

```text
node scripts/import-articles-to-supabase.mjs --apply
```

Импорт не меняет тексты и заголовки. Старый адрес записывается в `legacy_path`,
новый понятный адрес создаётся отдельно. Папка `src/data/countries` остаётся
единственным главным источником стран, писателей и литературной энциклопедии.
В ней хранится архив из 4000 карточек. Автоматически собранные 2356 записей
имеют статус `draft` и не показываются читателям до ручной проверки имени,
страны, биографии, произведений, источников и прав на портрет.

## Изображения

Портреты не генерируются. В медиатеке хранятся:

- имя автора изображения;
- исходная страница;
- название и ссылка лицензии;
- подпись;
- alt-текст;
- коллекция.

SVG сознательно не загружается: активное содержимое в SVG создаёт лишний риск.
JPEG, PNG, WebP и AVIF очищаются от метаданных, уменьшаются до 2400 px и
публикуются в WebP.

## Публикация

При статусе «Опубликована» кабинет может вызвать
`PUBLIC_SITE_DEPLOY_HOOK_URL`. Публичная сборка получает только опубликованные
материалы через RLS. Черновики и редакционные данные анонимному пользователю
недоступны.

Перед выпуском:

```text
npm run build:all
npm run test
npm run links:audit
```
