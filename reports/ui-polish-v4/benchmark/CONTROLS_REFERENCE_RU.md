# Кнопки полки: наблюдения по Linear

Дата: 08.09.2026. Источник: [официальная главная Linear](https://linear.app/). Самостоятельный просмотр: Chrome, 1440x1000 и 390x844, DPR 1. Без входа/отправки данных.

| Наблюдение | Применение к полке |
| --- | --- |
| Навигация и главный action имеют высоту 32px, padding по 12px. | Одинаковая геометрия соседних действий; сохранить наши мобильные цели 44px. |
| Обычные действия: 13px/400; главный action: 510. | Иерархия через поверхность; прежний Onest, умеренный вес, без повсеместного bold. |
| В превью строки: radius 8px, gap 8px; наружные actions округлее. | Один согласованный радиус внутри группы; две строки разделять назначением, без россыпи разных форм. |
| Открытое меню меняет фон, сохраняя размер и вес; aria-expanded переключается Enter/Escape. | Активный режим отличается поверхностью и aria-pressed; ширина и подпись не прыгают. |
| Desktop keyboard focus: outline 1px, offset 2px, отдельно от активной заливки. Mobile меню: 64x64px. | Отдельный заметный focus-ring; адаптировать группы, сохраняя размеры управления. |

Первоисточник наблюдений за desktop focus, меню и превью: [официальный сайт Linear](https://linear.app/). Raw captures чужого сайта сохраняются только локально и исключены из Git-набора доказательств. [Измерения](linear-controls-ready/observations.json).
