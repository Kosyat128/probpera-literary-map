# Узкая проверка прав: три архивных портрета для реальных R10 новостей

26.09.2026 проверены четыре варианта для трёх существующих карточек. Три подготовлены как **кандидаты**, один оставлен held. Это отдельное исследование social media; реестр активов и 101 миниатюра сайта не изменялись. Runtime-публикаций и API uploads: **0**.

Все подписи включают имя, архивный характер и дату фотографии. Фото публичных персон используется для редакционного сообщения о названном авторе; оно не должно создавать впечатление личной поддержки издания, канала или сервиса.

`proposed-assets.json` содержит согласованную с `scripts/lib/literary-news-media.mjs` структуру: точный news ID, source URL/SHA-256, license evidence URL/SHA-256, author/rightsholder/credit, permitted transformations, дату проверки, 30-дневный срок повторной проверки, descriptor нормализованной JPEG и результаты HTTP. Здесь **status=held, permissions=[]**: нет проверенных numeric Telegram/VK destinations. Назначения не придуманы; этот файл не runtime manifest. Перед возможным включением нужно сохранить отдельное разрешение/основание обработки для каждого проверенного назначения и повторно подтвердить актуальность evidence.

Оригиналы были прочитаны с HTTPS через существующий pinned-DNS transport; изображения полностью декодированы настоящим `normalizeNewsMedia`. Производные в `derivatives/` - JPEG, сторона не более 1600, без crop и увеличения исходника, со снятыми метаданными. Каждая из трёх производных действительно открыта и осмотрена: лицо и композиция сохранены, у фотографии Миллей сохранена исходная рамка. Source SHA-256 и derivative SHA-256 раздельны. Оригиналы находятся только в рабочем `.tmp/r10-rights-originals/`.

Для каждого кандидата дополнительно вызван настоящий `checkedNewsMediaAsset` с условным `status=approved`, но пустым permissions. Он отказал с `media_destination_not_licensed`; фиктивное назначение использовалось только как аргумент изолированной отрицательной проверки и не записано в manifest или permissions. Исследование не означает human approval, подключение канала или визуальную приёмку Telegram/VK. Сохранённые локальные JPEG - проверка декодирования и редакционного соответствия, не снимки социальных площадок.
