# Итоговая матрица глобусов

Дата среза: 1 сентября 2026 года. В интерфейсе доступны девять изданий. M-101 1943 остаётся выбранной альтернативой. Эта матрица не приравнивает «файл загружается» к строгому прохождению всех требований.

## Статусы A-D

| Издание | Gate A: источник/права | Gate B: реконструкция | Gate C: рисунок → канонический контур | Gate D: продукт |
|---|---|---|---|---|
| Behaim 1492 | PASS | PARTIAL | **NOT PASSED:** глобальная подгонка потребовала бы выдумать отсутствующую географию | PARTIAL: целевые проверки пройдены, полный E2E не запускался |
| Hondius 1615 | PASS | PARTIAL | **NOT PASSED:** независимые fit/holdout residuals отсутствуют | PARTIAL |
| Coronelli 1697 | PASS | PARTIAL | **NOT PASSED:** независимые fit/holdout residuals отсутствуют | PARTIAL |
| Scherer 1700 | PASS | PARTIAL: архивный мастер не повышен в production | **FAIL:** pilot p95 41.817404 px при цели 1 px на 1024 × 512 | PARTIAL |
| Cassini 1790 | PASS | PASS | **NOT PASSED:** 0 px относится к нанесённой канонической линии, а не к гравюре | PARTIAL |
| Rand McNally 1887 | PASS | принятый legacy baseline | принятый визуальный baseline; строгий residual не измерен | PARTIAL |
| M-101 1943 | PASS при обязательном кредите David Rumsey | PASS для воспроизводимой репроекции и швов | **FAIL по текущему proxy:** p95 4 px при цели 2 px | PARTIAL |
| NASA Blue Marble | PASS при кредите NASA | N/A | N/A для исторического Gate C | PARTIAL |
| Natural Earth 2026 | PASS | N/A | N/A: это канонический современный источник | PARTIAL |

Gate A означает подлинный источник, совместимые права и закреплённую идентичность. Gate B проверяет реконструкцию, швы, полюса и сохранение исторического рисунка. Gate C относится только к самому историческому рисунку; его пороги на 2048 × 1024: median ≤ 1 px, p95 ≤ 2 px, maximum ≤ 6 px. Нулевой residual между SVG и линией, построенной из того же SVG, доказательством не является. Gate D требует итоговый интегрированный прогон продукта.

Пять ранних изданий используют безопасный профиль source-only-centroid-selection-v2: без ложной заливки флагом и без современного контура поверх несовпадающего рисунка. Это корректная защита интерфейса, но не PASS Gate C.

Сегодня подтверждены TypeScript, 71 целевой Vitest, 8 Python-тестов M-101, production build, бюджет ресурсов и целевая браузерная проверка девяти изданий на 1440, 390 и 320 px. Полный E2E-набор и deployment не запускались повторно, поэтому общий Definition of Done честно остаётся незакрытым.

Точные размеры, SHA-256, источники и права находятся в source-manifest.json.
